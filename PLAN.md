### Schema.org Templates

**FAQPage (all pages):**
```json
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "Question here",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Answer here"
      }
    }
  ]
}
```

**ItemList (listicle page only):**
```json
{
  "@context": "https://schema.org",

      "@type": "ListItem",
```
